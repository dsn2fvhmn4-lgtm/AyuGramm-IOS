# Initial feature map

The initial Ghost Mode preview is published. Development sources now include text edit/deletion history, formatting/reaction snapshots, bot capture controls, regex filtering, message details and silent-send modes; the expanded sources still require native/device verification. Other rows remain research only. Paths below are relative to each cloned repository. Other iOS entries are candidate integration areas, not verified hook implementations.

Android prefix A = `TMessagesProj/src/main/java/com/radolyn/ayugram/`.
