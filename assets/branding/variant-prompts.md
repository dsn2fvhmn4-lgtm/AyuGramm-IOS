# App-icon variant generation

Method: built-in image generation, two separate edits. Edit target:
`Telegram/Telegram-iOS/Telegram.icon/Assets/AyuGram.png` from the owner's artwork.
Generated images were inspected and copied into project assets without replacing
the purple original. The generated files retain the reference's 1254-pixel square
canvas; Icon Composer compiles the platform-specific outputs.

## Blue

Edit this app-icon artwork into a rich electric blue / navy color variant. Preserve
the exact central white Apple silhouette with the inset paper-airplane geometry
and its size and placement. Only recolor the purple background radial faceted
rays and the small lavender plane accent to blue. Flat full-bleed square 1024x1024
image, opaque, sharp clean edges. No rounded-corner mask, no outside margin, no
text, no border, no mockup, no added objects. This will be used directly as an iOS
app icon.
