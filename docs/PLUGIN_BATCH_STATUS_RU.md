# Плагины: поддержка и расширение движка

Актуальная партия `.iosplug` описана в [IOSPLUG_BATCH.md](IOSPLUG_BATCH.md). Ниже сохранён предыдущий отчёт для старого формата `.plugin`.

Проверены 29 уникальных исходников. API 8 добавил Group Mentions, Reactions Total и частичный petpet; API 9 добавляет formatted copy и расширенные фильтры Search+. Остались 20 не реализованных плагинов; Search+ и petpet по-прежнему имеют указанные ограничения.

Для API 9 нужна одна новая базовая IPA. После её установки совместимые подписанные адаптеры добавляются через ⟳. В каталоге №6 всего 11 записей: API 7 использует прежние 7, API 8 — прежние 10, API 9 — все 11. Новые функции поискового интерфейса появляются с базой API 9; его старый адаптер сохраняет совместимость.

## Готовые адаптеры и тестовые файлы

API 7: Camera Flip, Chat Colors, Arcade Games, Unlim Accounts, частичный Search+, Android branch-hook demo и OTA lowercase demo. API 8 добавляет Group Mentions, Reactions Total и частичный petpet. API 9 добавляет formatted copy и фильтры Search+. Демонстрационные плагины нужны для проверки, а не обозначают перенос остальных функций.

## Проверка именно OTA без переустановки

1. Открой exteraGram → Плагины. Используй IPA с кнопкой ⟳ возле плюса.
2. Для чистого сравнения до обновления попробуй импортировать [ota_lowercase_demo.plugin](../plugins/ota_lowercase_demo.plugin). Если каталог ещё не загружен, этот файл должен быть отклонён встроенным конвертером: в нём есть helper-метод вне его поддерживаемого подмножества.
3. Нажми ⟳ и дождись успешного обновления. Для старой IPA API 7 доступны прежние 7 записей; новые записи API 8 требуют обновления приложения. Если каталог уже загружался, шаг с первоначальным отказом пропускается; это не ошибка.
4. Через + импортируй тот же неизменённый `ota_lowercase_demo.plugin`, подтверди установку и включи.
5. В Избранном отправь обычный текст `OTA TEST AbC`. Ожидается `ota test abc`. Для теста отключи другие преобразующие текст плагины; не используй медиа, подпись или форматированный текст.
6. Выключи плагин и повтори: текст должен сохраниться как введён. Перезапусти приложение и проверь сохранение включённого состояния.
7. Затем импортируй оригинальные Camera Flip, Chat Colors, Arcade Games или Unlim Accounts из подборки и проверь их функции.

Эти четыре плагина также распознаются встроенными адаптерами, поэтому один только их успешный импорт ещё не доказывает загрузку OTA-каталога. Тест lowercase нужен именно для такого различения. Обновление списка само не устанавливает плагины и не заменяет уже установленный адаптер без подтверждения.

## Следующий этап движка

Причины и необходимые интерфейсы для оставшихся 20 плагинов и частично перенесённых функций сохранены в [машиночитаемом списке](PLUGIN_BATCH_STATUS.json), с SHA-256 исходников и координатами точек входа. Это план работ, не список реализованных функций. Приоритет реализации отдельно выбирается в следующей задаче. Операции удаления требуют подтверждения и отмены; таймеры историй/архивации учитывают ограничения iOS в фоне. Bubble Pop можно переносить внутри клиента, но исходное наложение поверх чужих приложений не является доступной возможностью обычной IPA.
