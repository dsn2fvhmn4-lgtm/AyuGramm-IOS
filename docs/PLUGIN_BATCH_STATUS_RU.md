# Плагины из подборки: поддержка и план переноса

Проверены исходники всех 28 переданных файлов. Поддерживаются 4 нативных адаптера; 24 требуют расширения движка. В этом изменении код приложения и возможности движка не расширяются. Загрузка каталога и импорт не выполняют оригинальный Python, DEX или Android UI.

Поддержка здесь означает наличие адаптера и проверку его импорта/активации на моделях, а не успешную проверку каждого жеста или экрана на iPhone. Результат OTA-теста на устройстве ещё нужен.

## Все готовые адаптеры каталога

1. Camera Flip: жесты переключения камеры кружков.
2. Chat Colors: цвета строк списка чатов.
3. Arcade Games: 2048, Flappy Bird, Chrome Dino.
4. Unlim Accounts: локальный лимит 999.
5. Search+: поиск в текущем чате по нескольким фразам; до 6 фраз и до 40 результатов на фразу. Поиск людей по ID/телефону, глобальная инъекция и оригинальные Android-фильтры в этот адаптер не входят.
6. Android branch-hook demo: тест ограниченной программы преобразования текста.
7. OTA lowercase demo: тест обновления каталога, приводит исходящий текст к нижнему регистру.

Последние два пункта являются тестовыми плагинами. Из 28 переданных файлов к поддерживаемым относятся только первые четыре. Совместимые простые текстовые плагины также может обработать встроенный конвертер, но это определяется по коду, а не по расширению файла.

## Проверка именно OTA без переустановки

1. Открой exteraGram → Плагины. Используй IPA с кнопкой ⟳ возле плюса.
2. Для чистого сравнения до обновления попробуй импортировать [ota_lowercase_demo.plugin](../plugins/ota_lowercase_demo.plugin). Если каталог ещё не загружен, этот файл должен быть отклонён встроенным конвертером: в нём есть helper-метод вне его поддерживаемого подмножества.
3. Нажми ⟳ и дождись успешного обновления. В опубликованном каталоге теперь 7 адаптеров. Если каталог уже загружался, шаг с первоначальным отказом пропускается; это не ошибка.
4. Через + импортируй тот же неизменённый `ota_lowercase_demo.plugin`, подтверди установку и включи.
5. В Избранном отправь обычный текст `OTA TEST AbC`. Ожидается `ota test abc`. Для теста отключи другие преобразующие текст плагины; не используй медиа, подпись или форматированный текст.
6. Выключи плагин и повтори: текст должен сохраниться как введён. Перезапусти приложение и проверь сохранение включённого состояния.
7. Затем импортируй оригинальные Camera Flip, Chat Colors, Arcade Games или Unlim Accounts из подборки и проверь их функции.

Эти четыре плагина также распознаются встроенными адаптерами, поэтому один только их успешный импорт ещё не доказывает загрузку OTA-каталога. Тест lowercase нужен именно для такого различения. Обновление списка само не устанавливает плагины и не заменяет уже установленный адаптер без подтверждения.

## Следующий этап движка

Причины и необходимые интерфейсы для всех 24 ожидающих плагинов сохранены в [машиночитаемом списке](PLUGIN_BATCH_STATUS.json), с SHA-256 исходников и координатами точек входа. Это план работ, не список реализованных функций. Приоритет реализации отдельно выбирается в следующей задаче. Операции удаления требуют подтверждения и отмены; таймеры историй/архивации учитывают ограничения iOS в фоне. Bubble Pop можно переносить внутри клиента, но исходное наложение поверх чужих приложений не является доступной возможностью обычной IPA.
