# Расширение движка плагинов API 8

Это реальное расширение нативного движка. Для новых действий нужна одна новая базовая IPA; обновление списка на старом API 7 само не добавляет Swift-код. Совместимость с прежними адаптерами API 1–7 сохраняется. Каталог указывает минимальную версию каждого адаптера, старое приложение пропускает новые действия и сообщает о необходимости обновления.

## Group Mentions

- Импорт оригинального `group_mentions.plugin`, автор @Hikerys.
- В настройках плагина появился экран «Группы упоминаний»: до 5 групп по 7 юзернеймов.
- Можно добавлять, редактировать и удалять группы. Например: команда `друзья`, участники `@alice @bob`.
- Настраиваются регистр, применение в личных чатах и группах.
- Сначала проверяются длинные команды; замена применяется к целой команде, а не к частям слов и существующим @упоминаниям. Вставленный текст не обрабатывается повторно.
- Кулдаун 60 секунд изолирован по аккаунту, чату и плагину. Длина результата ограничена; при превышении сохраняется исходный текст.
- Настройки сохраняются вместе с аккаунтом, переживают перезапуск и замену адаптера. Экспорт самого плагина не раскрывает пользовательские группы.

Обрабатываются обычный текст и неформатированные подписи. Каналы, секретные чаты, форматированные сообщения и запланированная отправка исключены. При отключении плагина преобразования не выполняются.

## Reactions Total

- Импорт оригинального `reactions_total.plugin`, автор Daxo-Developer @Daxo_OS.
- Сумма реакций отображается в общей строке времени сообщения. Данные сообщения и подпись автора не изменяются.
- Настройки: ♥, Σ или число; сокращение 1200 → 1.2K; минимум реакций; только каналы; исключение платных реакций; расположение до или после времени.
- Настройки хранятся отдельно в каждом аккаунте. Переполнение счётчика не приводит к падению.

Теги в Избранном и сообщения вне обычной облачной истории исключены. Изменение настроек становится видно при обновлении ячейки или повторном открытии чата. Android debug bulletin не переносится.

## petpet: первый нативный медиа-адаптер

- Импорт оригинального `petpet.plugin`, автор @limeplug.
- Запуск из меню плагинов в чате либо командами `.petpet` и `.петпет`. Эти команды открывают редактор и не отправляются собеседнику.
- Источник: аватарка текущего чата или изображение из приложения «Файлы». Для фотографии из галереи сначала сохрани её в «Файлы».
- Оригинальные 10 кадров руки извлечены как данные изображений; исходный Python не запускается.
- Нативная композиция сжатия изображения и GIF-кодирование через UIKit/ImageIO, анимированный предпросмотр.
- Размеры 64/128/256/512; задержки кадра 20/30/40/50/70/100 мс. Эти предпочтения сохраняются по аккаунту.
- Ограничение входа 8 МБ и 64 МП, уменьшение при декодировании. Прозрачные кадры очищаются перед следующим, чтобы избежать следов при воспроизведении.
- Отправка выполняется кнопкой после предпросмотра, через существующий механизм GIF в Telegram. Перед отправкой повторно проверяются чат, режим редактирования, общая возможность отправки и включённое состояние плагина.

Этот адаптер частичный. Ещё отсутствуют аргументы URL/@username, загрузка медиа из ответа, TGS/видео-стикеры и исходные пункты меню профиля/сообщения. Команды с аргументами не являются поддерживаемым способом запуска. Штатный механизм Telegram может преобразовать GIF в видео при отправке; предпросмотр является GIF.

## Общие изменения

- Реестр вмещает до 64 плагинов вместо 12.
- API 8 добавляет типизированные действия `groupMentions`, `reactionsTotal`, `petpet` и соответствующие разрешения.
- В API 7 эти действия не принимаются. Подписи адаптеров API 8 проверяются тем же закреплённым ключом, откат каталога и подмена содержимого отклоняются.
- Каталог №5 содержит 10 записей: 7 прежних и 3 новых. Старый API 7 получает прежние 7 и сообщение о 3 требующих обновления.

## Проверки и оставшаяся работа

На macOS прошли 57 Python-тестов, 635 проверок настоящих Swift-моделей, проверка UIKit-экранов и нативного petpet-генератора компилятором SDK. Это не результат запуска на iPhone и не подтверждение полной сборки всех модулей Telegram. После публикации каталога добавлена дополнительная Python-проверка трёх подписанных API 8 адаптеров.

Все остальные плагины продолжают учитываться в [списке совместимости](PLUGIN_BATCH_STATUS_RU.md) и [машиночитаемой очереди](PLUGIN_BATCH_STATUS.json). Там явно отделены готовые адаптеры, частичный перенос и 21 ещё не реализованный плагин. Story Scheduler и расширенные возможности Search+ в этот блок не вошли.
