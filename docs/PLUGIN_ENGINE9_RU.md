# Движок плагинов API 9

Этот блок добавляет нативное форматированное копирование и расширяет интерфейс Search+. Для него нужна новая базовая IPA. Существующие адаптеры API 1–8 и сохранённые настройки продолжают использоваться.

## formatted copy

Импортируется оригинальный `formatted_copy.plugin` автора @meatdisk. На странице плагина есть переключатель «Копировать дату и время». Настройка хранится отдельно в аккаунте и сохраняется при обновлении адаптера.

1. Включи плагин.
2. Долгое нажатие на сообщение или альбом → **Копировать с подробностями**.
3. Для нескольких сообщений сначала выдели их, затем долго нажми **Поделиться** в панели выделения. С VoiceOver доступно отдельное действие «Копировать с подробностями» на этой кнопке.
4. Вставь результат в Избранное или текстовый редактор.

Формат соответствует основному текстовому представлению оригинального плагина:

```text
[27/10/2026 12:34:56] Alice:
↳ Bob: Текст доступного сообщения-ответа
└ Текст сообщения
```

Сообщения сортируются хронологически, даты показываются в часовом поясе телефона. Переносы строк основного текста сохраняются, имена и цитаты сводятся в одну строку. При отключённой дате её префикс полностью убирается.

Фото, видео, кружки, голосовые, музыка, стикеры, GIF, файлы, опросы, контакты и геопозиции получают текстовые отметки. Имя файла и доступная завершённая расшифровка голосового включаются в текст. Для недоступного исходного сообщения ответа показывается явная заглушка о недоступности, без выдуманной цитаты.

Обычное **Копировать** остаётся штатным. Новый пункт копирует простой текст с подробностями, не RTF, не оригинальные медиа и не их двоичные данные. Для опросов/контактов/геопозиций используются отметки типа, а не полная сериализация всех полей. Обрабатываются до 100 обычных облачных сообщений и 1 МБ результата. Копирование не выполняется для защищённых, истёкших или рекламных сообщений; ограничения текущего чата проверяются повторно перед записью в буфер. При исчезнувшем сообщении или превышении лимита частичный результат не подменяет буфер.

Запрос принадлежит контроллеру чата, отменяется при его уничтожении и не переносит результат в другой открытый чат. Долгое нажатие на «Поделиться» и дополнительное действие доступности подключаются только при включённом плагине.

## Search+: автор, период, тип медиа

В меню плагинов чата выбери Search+:

1. Выбери тип сообщений: все, фото, видео, файлы, музыка, голосовые/кружки или GIF.
2. Введи до шести фраз через `|`.
3. Необязательно укажи автора: `@username` или известный клиенту положительный ID пользователя.
4. Необязательно укажи даты начала и окончания как `ГГГГ-ММ-ДД`.

Даты относятся к часовому поясу телефона. Последний день включается целиком, включая переходы на летнее/зимнее время. Некорректные даты, обратный период и значения за диапазоном временных меток Telegram отклоняются.

Username разрешается штатным Telegram API. Для ID нужен сохранённый peer и пригодный InputPeer/access hash. Если этих данных нет, появляется ошибка; фильтр автора не сбрасывается и поиск «от всех» не запускается. Результаты дополнительно проверяются по автору и датам. Отмена и новый поиск инвалидируют предыдущие запросы; синхронный ответ из кэша не должен отменить следующий этап поиска.

Область остаётся прежней: текущий чат и тема, до 40 результатов на фразу, объединение без дубликатов. Пустые запросы, автоматическая пагинация, глобальная инъекция поиска и произвольный поиск людей по ID/телефону в этот блок не входят. Это фильтр отправителя сообщений, а не обход серверной доступности чужого профиля.

В каталоге Search+ сохраняет действие `searchTerms` API 7: на старой базе работает базовый поиск, на базе API 9 появляются новые элементы интерфейса. Для уже установленного адаптера типа `searchTerms` достаточно обновить базовую IPA; повторный импорт для появления самих фильтров не требуется.

## Каталог и проверки

Каталог №6 содержит 11 подписанных записей. У formatted copy минимальная версия API 9: старый движок пропускает запись и предлагает обновить базу. Ключ подписи прежний; установленный адаптер сохраняет проверяемую подпись при экспорте и повторном импорте без сети.

Перед полной сборкой на macOS прошли 59 Python-тестов, 655 проверок настоящих Swift-моделей и проверка экрана настроек компилятором. Дополнительно добавлены проверки подписанного API 9 адаптера и его повторного импорта. Интеграция со всеми модулями Telegram проверяется полной нативной сборкой; результат на iPhone требует проверки установленной IPA.

Состояние всей подборки: [список совместимости](PLUGIN_BATCH_STATUS_RU.md). Этот блок не означает реализацию остальных 20 плагинов.
