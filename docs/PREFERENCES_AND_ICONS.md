# Preferences panels and app icons - source after Release 3

The Settings entry reads **AyuGram** and uses the mod's own logo as a 30 pt
rounded Settings icon (the earlier outlined star rendered black and was replaced).
The AyuGram page is a native Telegram item list in the iOS Settings style: a
**Settings** section with colored category icons (**AyuGram** with the logo,
**Filters**, **General**, **Appearance**, **Chats**, **Plugins**), a **Links**
section (channel **@neosay1337**, source and documentation) and the project note.
The previous UIKit hub inside a LegacyController and the separate **Other**
category are gone.

Category pages list their rows in display order with positional ids.
ItemListController requires ascending stable ids; the earlier AyuGram, General and
Appearance pages used action ids out of order (for example 0, 50, 1, 53), which
fails MergeLists' precondition and crashed on opening.
Existing controls are grouped as follows:

| Category | Pages |
| --- | --- |
| AyuGram | Ghost Mode, Message History |
| Filters | Regex Filters |
| General | Sending Options, Interface, Message Menu |
| Appearance | Chat Appearance, MessageShot Appearance, App Icon |
| Chats | Hidden Messages, Chat Reactions |
| Other | Channel, source/documentation and project status |
| Plugins | Installation manager and individual plugin pages |

The plugin manager now uses a header and installed-plugin rows. Tapping a plugin
opens its own page: large generic puzzle icon, name, version, author, description,
enable switch, supported actions/limitations, export and confirmed removal. The
enable flow retains the existing local compatibility checks and adapter behavior.
Popping or closing that page cancels an uncommitted preparation result. This work
is complemented by the later [automatic hook-template import](PLUGIN_CONVERSION.md).

The common puzzle icon is drawn at the requested display size with preserved
symbol proportions. It is shared by plugin rows, headers and action lists.

## Next appearance block: native app-icon selection

Open **AyuGram Preferences -> Appearance -> App Icon**. Fifteen choices are supplied:
the owner's existing purple logo, **Blue**, **Graphite**, and the twelve original
AyuGram Desktop presets: Default, Alt, Discord, Spotify, Extera, Nothing, Bard,
Yaplus, Win95, Chibi, Chibi2 and Extera2. Original SVG/PNG files are copied without
redrawing, retaining their upstream Icon Composer scale and position. Selection requests the
system alternate-icon API; the selection marker changes only after success.
Failure retains the previous marker and displays an error. Returning to Original
requests the primary icon. The picker follows the app's overall light/dark style.

The main app declares fifteen Icon Composer bundles and explicitly names Telegram
as primary. Legacy `.alticon` insertion is disabled for this target because the
pinned legacy inserter overwrites the alternate-icon dictionary generated by
actool. The other bundles are declared as modern alternates in `app_icons`.

## References and artwork

Layout references: the supplied screenshots, the local Android
`AyuGramPreferencesActivity.java` and Desktop
`ayu/ui/settings/settings_main.cpp`. The local Android snapshot is from 2023 and
does not contain the modern plugin-manager source. This is a native UIKit/Telegram
adaptation of the reference structure; Android/Desktop code is not presented as
an already working iOS UI. Original AyuGram authors retain their attribution.

The owner's original Apple/airplane artwork is preserved. Blue and Graphite were
created using the built-in image-generation tool with that artwork as the edit
target. The final files are [Blue](../assets/branding/AyuGram-blue.png) and
[Graphite](../assets/branding/AyuGram-graphite.png). Full prompts are in
[artwork prompts](../assets/branding/variant-prompts.md). Copies are included in
the native source patch for UI previews and Icon Composer.

## Verification

Windows checks cover source grammar/import contracts, PNG/JSON references,
compiler rule configuration and clean application to pinned upstream. The early
macOS preflight now SDK-checks the UIKit hub, icon picker and actual plugin pages,
and compiles all declared Icon Composer bundles before the expensive Telegram build.
The packaged IPA check requires every declared alternate-icon name in Info.plist.

Native compilation, icon switching and recorded simulator/device verification
remain pending the owner's manual Codemagic run. Release 3's uploaded IPA is
unchanged. Before claiming visual verification, record and inspect frames for:
opening the star entry; hub/categories without the large header; every category and link; plugin
details/toggle/back/cancel/export/remove; icon selection/success/failure/primary
reset; light/dark themes, narrow and iPad layouts, large fonts and VoiceOver.
