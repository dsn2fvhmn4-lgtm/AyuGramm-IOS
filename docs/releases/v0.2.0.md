# AyuGram for iOS v0.2.0 — Feature Preview (build 8)

An unofficial native Telegram-iOS adaptation based on Telegram 13.1.1. This preview expands the original Ghost Mode release with local history, media controls, interface settings and MessageShot. Full AyuGram Android/Desktop feature parity is still in progress.

## Where to find the settings

Open **Settings → AyuGram · Ghost Mode** near the top of Settings to reach the AyuGram settings hub. The **Settings → Privacy and Security → AyuGram · Ghost Mode** entry remains available.

The hub contains **Ghost Mode**, **Message History**, **Sending Options**, **Regex Filters**, **Chat Appearance** and **Interface**.

## Features and changes

- **Ghost Mode:** per-account controls for cloud-chat read receipts, explicit online status, typing/recording and upload activity. The chat-header ghost button toggles the mode and shows its local state. Hide Online reasserts offline status after an accepted cloud-message send; brief server-visible activity remains possible.
- **Message History:** opt-in local edit/deletion capture, inline deleted-text retention and a Deleted mark beside the timestamp. Optional formatting, reaction snapshots, bot-message capture and cached-media archiving. Message menus include message details and access to saved history. Text history is bounded to 100 entries, 8 KB each and seven days; cached attachments are limited to 25 MB each and 250 MB per account. This does not recover messages that were never locally available. Protected, secret and expiring content is excluded.
- **Sending Options:** silent sending always or only in Ghost Mode; independent sticker/GIF confirmations and preview before ordinary voice/video-note sends. These media confirmations default off. View-once recording sends retain their native flow.
- **Regex Filters:** local filtering of loaded messages, with case-insensitive matching and optional use outside channels. This is a display filter, not server-side deletion.
- **Chat Appearance:** show/hide the header ghost button, timestamp seconds and custom edited/deleted labels. Reset affects appearance only.
- **Interface:** copyable user/group/channel IDs in profiles, ordinary bubble quick-share hiding and Chats-tab unread-badge visibility. Comment/sponsored actions and the system app-icon badge retain their native behavior.
- **MessageShot:** long-press a message → **AyuGram · MessageShot**, or select messages → **Share → MessageShot**. Create a card image with authors, formatted text, dates and cached previews, review/zoom it and use the system share sheet. Up to 20 accessible messages from one chat; spoilers stay masked and protected/expiring content is excluded. This is a composed card image rather than a pixel-identical screenshot of the chat.
- **Branding and fixes:** AyuGram app branding and icon; source fixes for settings-observer re-entry, Postbox history serialization, ghost-header initialization and the MessageShot Swift capture error.

## Verification and limitations

The ZIP integrity, app metadata and arm64 iPhoneOS Mach-O platform were checked. The packaged UI framework contains the MessageShot and new interface-setting strings. Source baseline: `01257b5`; the downloaded IPA contains no build manifest independently linking it to that commit. The maintainer reports testing on an iPhone.

Ghost Mode is not an absolute-invisibility guarantee: other devices, sending and server-side behavior may expose activity. Story views, secret-chat reads, media consumption and expiration keep upstream behavior. Server Premium entitlements are unchanged. Ghost Mode conflicts with Telegram API Terms section 1.4. This project is unofficial and is not affiliated with Telegram or the original AyuGram maintainers.
