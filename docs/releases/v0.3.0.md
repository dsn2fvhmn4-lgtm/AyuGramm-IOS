# AyuGramm-IOS - Release 3

Unofficial native Telegram-iOS adaptation. Download **AyuGramm-IOS.ipa** from
[Release 3](https://github.com/dsn2fvhmn4-lgtm/AyuGramm-IOS/releases/tag/v0.3.0-preview).

## Changes since Release 2

1. Message-menu controls: independently show or hide the reaction picker, read/reaction summary, edited-time header and AyuGram message details.
2. Search messages from a selected author in groups using native Telegram search.
3. Create a filter draft directly from message text, with literal punctuation escaping, saved/editor rule counts and confirmed rule clearing.
4. MessageShot appearance settings: app/light/dark theme and separate controls for background, author names, dates, header and cached media previews.
5. Repeat message text into the current draft with formatting and confirmation. Nothing is sent automatically.
6. Find a message phrase using native in-chat search.
7. Copy chat and message IDs from the message menu.
8. Hide messages and albums locally, with a hidden-items manager, individual restoration, restore-all and temporary display bypass. Server messages remain unchanged.
9. Independently show or hide message reactions in private chats, groups and channels.
10. Updated app icon using the supplied Apple/airplane artwork without the exterior black surround.

## Fixes and reliability

11. Corrected channels-only filtering so broadcast channels and supergroups are distinguished.
12. Corrected MessageShot inner-width validation before image rendering.
13. Added isolated startup storage when the expected App Group or shared Keychain access is missing.
14. Added a diagnostic screen for detected storage initialization failures in place of the previous generic error path; removed forced passcode-environment initialization.
15. Added database-directory creation before key generation, existing-key validation and a key-persistence check before opening the database.
16. Expanded early SDK checks, startup-storage regression coverage and direct-module dependency checks before the full native build.

These are the repository changes prepared since Release 2. The uploaded IPA has
no independently verified source-commit manifest. ESign and LiveContainer compatibility is not
confirmed for every setup. In isolated storage mode, another login may be needed;
the wallet and shared-container extensions are unavailable. Existing shared data
is retained. Full Android/Desktop feature parity remains in progress.

## Settings

Open **Settings -> AyuGram / AyuGram Ghost Mode** near the top of Settings.
Additional controls are grouped under Message Menu, Regex Filters, MessageShot
Appearance, Hidden Messages and Chat Reactions.
