# AyuGramm-IOS - Release 4

Unofficial Telegram-iOS adaptation. This release packages the latest successful native Actions build, from commit `bfb6ca02e81bd689d62d87b3042f0868c473d06e`.

## Changes since Release 3

1. Rebuilt AyuGram preferences as native Telegram item lists, with category icons, the project logo and channel @neosay1337. Corrected row ordering that could crash category pages.
2. Added the plugin manager, plugin detail/settings pages, import-and-enable confirmation, export and removal. Plugins use a shared puzzle icon.
3. Added on-device conversion of supported outgoing-text hook templates, including conditions and counted replacements. Import validates compatibility and replaces plugins atomically.
4. Added 15 app-icon choices, including the custom logo variants and original AyuGram presets.
5. Added Ghost Mode+ settings: delayed plain-text sending and optional mark-read-after-send. The two modes are mutually exclusive.
6. Added manual message translation through Telegram, LibreTranslate and DeepL Free/Pro, with provider keys stored in the Keychain.
7. Added chat export to HTML/JSON with a date range and available cached media, or forwarding eligible history to Saved Messages. Export is not full Telegram Desktop format parity; media is not automatically downloaded.
8. Added the media archive manager with quotas, file export and removal while retaining text history.
9. Added local Premium presentation, local emoji status/animation controls and custom-emoji link rendering. Server subscription and server-enforced limits remain unchanged.
10. Extended Repeat with a send-copy action for eligible media messages.
11. Improved early source/SDK checks and switched the default native configuration to optimized release_arm64.

## Python plugin runtime status

Commit bfb6ca0 adds a desktop-tested Python SDK compatibility prototype and hook mapping/report tools to the repository. It does not embed CPython or enable arbitrary Python plugins in this IPA. Story Scheduler has no native adapter. Universal plugin conversion is not implemented.

The subsequent commits 1f17ba3 and 1dc05cd attempt native Python-host integration and compile-risk fixes. They are excluded from this release. The latest run failed in preflight because AyuAdvancedSettings.swift, AyuChatExportModels.swift and AyuTranslationRequest.swift were missing from the generated source tree.
