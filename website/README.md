# Страница установки VoidGram

Локальный макет сайта. Открой `dist/index.html` в браузере. Сборка и установка
пакетов не нужны; шрифт, логотип, стили, скрипты и снимки владельца находятся
в `dist/`. Изображения Apple и Expo для шагов 3 и 6 загружаются с сайтов источников
и требуют интернета.

Для просмотра через HTTP из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Затем открой `http://127.0.0.1:4173`. Для размещения на статическом хостинге
достаточно содержимого `dist/`. Сайт опубликован на GitHub Pages:
https://neosay-dev.github.io/VoidGram/ — workflow `.github/workflows/pages.yml`
выкладывает `dist/` при каждом пуше в `website/`.

## Что работает

- Шесть шагов установки с прямыми ссылками и выбором Windows / macOS / Linux.
- Отметки пройденных шагов и выбранная ОС сохраняются локально в браузере.
- Прямые ссылки вида `#step-4`, переходы назад/вперёд, сброс отметок.
- FAQ на стандартных HTML `details`, навигация с клавиатуры и режим печати.
- Без JavaScript показаны все шаги; скачивание доступно по ссылкам.
- Скриншоты открываются в исходном размере в диалоге с прокруткой.
- В шаге 6 можно переключать три экрана настроек iOS.
- Узкие снимки в шагах 1 и 5 прокручиваются по горизонтали на телефоне.
- При ошибке загрузки остаются схема шага, инструкция и ссылка на источник.
- Адаптивная раскладка и отключение анимации при `prefers-reduced-motion`.

Сайт не принимает Apple Account, пароли или коды и не выполняет подпись IPA.
Вход и установка происходят в iLoader на компьютере пользователя.

## Скриншоты

Снимки подключены через `screenshots` в `dist/site-config.js`:

| Шаг | Изображение | Откуда |
| --- | --- | --- |
| 1, Windows | Загрузка `iloader-windows-x64.exe` | Первый снимок владельца, `01-iloader-windows.webp` |
| 2 | Кнопка «Скачать IPA» на главной странице | Второй снимок владельца, `02-download-ipa.webp` |
| 3 | Запрос Trust This Computer? на iPhone | [Apple Support](https://support.apple.com/109054) |
| 4 | iLoader после входа в Apple Account | Третий снимок владельца, `04-apple-account.webp`; почта скрыта |
| 5 | Файл IPA в загрузках | Четвёртый снимок владельца, `05-select-ipa.webp` |
| 6 | Настройки, перезапуск и подтверждение режима разработчика | [Expo Docs](https://docs.expo.dev/guides/ios-developer-mode/) |

Снимок шага 5 показывает выбор файла, а не успешное завершение установки.
Для macOS и Linux в первом шаге остаётся иллюстрация с меткой «Схема».
Изображения Apple и Expo показывают английский интерфейс iOS 16; названия кнопок
переведены в подписях. Оформление новых версий iOS может отличаться.

Четыре локальных снимка сохранены в WebP без потери качества. В снимке iLoader
область почты необратимо уменьшена до нескольких пикселей и размыта перед
сохранением. Оригинал с читаемой почтой в `dist/` не добавлен; CSS для сокрытия
данных не используется. Остальная часть снимка сохранена без изменений.

Обычный шаг принимает объект, а галерея — массив объектов:

```js
ipa: {
  src: 'assets/steps/02-download-ipa.webp',
  width: 629,
  height: 472,
  alt: 'Главная страница VoidGram с кнопкой «Скачать IPA»',
  caption: 'Нажми «Скачать IPA» и дождись завершения загрузки.',
},
```

Необязательные поля: `layout: 'strip'` для узкой строки, `layout: 'phone'` для
снимка телефона, `label` для кнопки в галерее и `source: { label, url }` для
ссылки на источник. Для каждой ОС iLoader используется отдельный ключ:
`iloader.windows`, `iloader.macos`, `iloader.linux`. Значение `null` оставляет схему.

Прямые адреса внешних изображений:

- [Apple: Trust This Computer](https://cdsassets.apple.com/live/7WUAS350/images/ios/ios-16-iphone-14-pro-trust-this-computer-prompt.png).
- [Expo: путь к Developer Mode](https://docs.expo.dev/static/images/ios-dev-mode/ios-16-developer-mode-1.webp).
- [Expo: перезапуск](https://docs.expo.dev/static/images/ios-dev-mode/ios-16-developer-mode-2.webp).
- [Expo: подтверждение после перезапуска](https://docs.expo.dev/static/images/ios-dev-mode/ios-16-developer-mode-3.webp).

Адреса и соответствие инструкциям проверены через веб-поиск. Скачать эти файлы
в рабочую папку не удалось из-за недоступности DNS в среде исполнения, поэтому
в конфигурации оставлены HTTPS-ссылки. Если нужна полностью автономная страница,
сохрани изображения в `dist/assets/steps/` и замени только `src`, сохранив `source`.
Если внешний сервер недоступен, сайт показывает схему и ссылку на инструкцию.

## Ссылки и актуальность

Проверено по первичным источникам 1 ноября 2026 года:

- [Релизы VoidGram](https://github.com/neosay-dev/VoidGram/releases):
  в макете выбрана 27.0.2, build 88, файл `AyuGramm-IOS-27.0.2.ipa`.
  При новом релизе обновить `release` в `site-config.js`; ссылка «Все версии»
  всегда ведёт на список релизов.
- [Официальный сайт iLoader](https://iloader.app/) и
  [репозиторий разработчика](https://github.com/nab138/iloader): ссылки на
  установщики, драйверы и импорт своего IPA. Ссылки iLoader используют `latest`.
- [SideStore: установка через iLoader и доверие аккаунту в iOS](https://docs.sidestore.io/docs/installation/install).
- [Apple: Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).
- [Apple: ограничения Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account).

Проверены синтаксис JavaScript, уникальность HTML ID, якоря, локальные файлы
и прозрачность логотипа. Дополнительно проверены декодирование локальных WebP,
скрытие почты и соответствие подписей снимкам. Временной проверкой с имитацией DOM
проверены переключение галереи и ОС, запоздавшие события загрузки, ошибка внешнего
изображения, повторная загрузка и открытие увеличенного снимка. Браузерная проверка
раскладки и взаимодействий в этой
среде не выполнена: Firefox завершается при запуске, а WebKit не имеет доступа
к дисплею. До публикации проверить страницу в Safari на iPhone и настольном браузере.
